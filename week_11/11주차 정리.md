
## 토큰 시스템 구현
### 기본 토큰 컨트랙트
- #### 토큰
	- 블록체인 네트워크 위에서 발행하고 관리되는 디지털 자산
	- 특정 응용 시스템을 구현하기 위해 스마트 컨트랙트 코드로 정의
		- 발행량, 전송, 소각 등의 규칙 지정
- #### 코인과 토큰 차이
	- ##### 코인
		- 자체 블록체인을 가진 암호 화폐
		- 프로토콜에 따라 자동 발행
		- 블록체인 전체 생태계에서 사용
	- ##### 토큰
		- 기존 블록체인 위에서 발행되는 디지털 자산
		- 스마트 컨트랙트에서 규칙을 코드로 정의
		- 특정 서비스 안에서 주로 사용
		- ex) ERC-20 기반 스테이블 토큰
- #### 기본 토큰 만들기
	- 토큰의 기본적인 기능만 구현
		- 잔고 저장, 로그 기록, 송금
- #### 구현 및 기능 개요
	- 상태 변수 name, symbol, decimals, totalSupply
	- 매핑 mapping(address => uint)으로 잔고 관리
	- 생성자를 통해 초기 발행
	- transfer 함수로 송금 로직 구현
	- event로 로그 남기기
- #### 상태변수
	- `string public name; // Token Name`
	- `string public symbol; // Token 단위`
	- `uint8 public decimals; // 소수점 이하 자릿수`
	- `uint public totalSupply; // 토큰 총량`
- #### 매핑과 이벤트
	- `mapping(address => uint) public balanceOf; // 각 주소의 잔고`
	- `event Transfer(address from, address to, uint amount);`
- #### 생성자
	- 이름, 단위, 소수점 이하 자릿수 지정
	- 소수점 이하 자릿수 표현 방법
		- 기본 단위의 발행량(supply)에 10^decimals 를 곱하는 형식으로 총 발행량 설정
		- 배포자가 전체 물량을 갖고 시작
		- 컨트랙트 내부에서는 토큰의 최소 단위로 동작
- #### transfer() : 송금 함수
	- 호출자(msg.sender)에서 수령자로 잔고를 옮기는 기본 송금 로직
	- 에러처리로 잔액 부족 및 오버플로우 방지
		- 오버플로우의 경우 0.8.x 버전부터는 자동 체크
	- 상태 변경 후 이벤트를 발생
		- 프론트엔드와 백엔드가 컨트랙트 변화를 쉽게 감지
		- 체인 위 검색 가능한 히스토리 기록
		- 표준화 인터페이스(ERC-20)의 명세 사항

### 추가 기능 - 블랙리스트
- #### 블랙리스트
	- 소유자(배포자)만 블랙리스트를 관리
		- 블랙리스트에 기록된 주소는 입출금 불가
		- 소유자만 블랙리스트에 계정 주소를 추가 및 삭제 가능
		- 소유자 여부는 주소로 식별하고 컨트랙트 생성할 때 주소를 소유자로 생성
- #### 상태변수 & 매핑
	- `address public owner; // 소유자 주소` 추가
	- `mapping(address => bool) public blackList; // 블랙 리스트` 추가
- #### 제한자 & 이벤트
	- `modifier onlyOwner() { require(msg.sender == owner, unicode"No Permissioned"); _;`
	- `event Blacklisted(address target);`
	- `event DeleteFromBlacklist(address target);`
- #### 생성자
	- `owner = msg.sender;` 추가
- #### 블랙리스트 등록 & 삭제
	- ```solidity
	  function blacklisting(address addr) external onlyOwner {
	    blackList[addr] = true;
	    emit Blacklisted(addr);
	  }
	  
	  function deleteFromBlacklist(address addr) external onlyOwner {
	    blackList[addr] = false;
	    emit DeleteFromBlacklist(addr);
	  }
	  ```
- #### transfer()
	- 잔고를 변경하기 전 보내는 주소가 블랙리스트에 있는지 확인
	- 받는 주소도 블랙리스트에 있는지 확인
	- 모두 통과 시 잔고를 변경하고 이벤트 기록
### 추가 기승 - 캐시백
- #### 구현 개요
	- 송금 시 수신자가 미리 설정해 둔 캐시백 비율 만큼 토큰을 돌려줌
	- 각 주소는 소유주의 허가 필요 없이 자신의 캐시백 비율만 설정 가능
		- 각 주소는 캐시백 비율을 0-100 범위로 설정
	- 소유주라 할지라도 타인의 비율은 변경할 수 없음
- #### 상태 변수 & 매핑
	- `mapping(address => uint) public cashbackRate; // 각 주소의 캐시백 비율`
- #### 제한자 & 이벤트
	- `event SetCashback(address addr, uint rate);`
	- `event Cashback(address from, address to, uint amount);`
- #### setCashbackRate() : 캐시백 비율 설정
	- ```solidity
	  function setCashbackRate(uint rate) external {
	    if(rate > 100) rate = 100;
	    cashbackRate[msg.sender] = rate;
	    emit SetCashback(msg.sender, rate);
	  }
	  ```
- #### transfer()
	- 캐시백을 실제 돌려주지 않고 지정된 송금액에서 캐시백 금액을 제외하고 송금
		- 비율이 0이면 캐시백이 없는 것이고 100이면 모든 금액을 돌려주는 개념
### 추가 기능 - 회원 관리
- #### 구현 및 기능 개요
	- 회원 관리를 통해 사용자 별 이용 금액과 이용 횟수를 기록해 캐시백 비율을 변경
		- 소유자는 회원 관리 기능을 가지는 관리자 역할을 함
		- 회원 식별은 주소로 하고, 회원 관리 기능은 회원별 거래 횟수, 금액을 기록함
		- 최저 거래 횟수, 최저 거래 금액을 설정하여 등급을 지정
		- 이용 횟수와 금액을 충족하면 등급이 상승하고 이에 따른 변경된 캐시백 비율을 설정
	- 소유자 관리 기능을 간결하게 작성하고 다른 컨트랙트에서 이를 상속함
- #### 회원 관리용 컨트랙트
	- 구조체
		- 회원 관리용, 거래 이력용
		- ```solidity
		  struct GradeStatus {
		    string grade; // 등급
		    uint times; // 해당 등급을 위한 최저 거래 횟수
		    uint sum; // 해당 등급을 위한 최저 거래 금액
		    uint rate; // 캐시백 비율
		  }
		  
		  struct MemberHistory {
		    uint times; // 거래 횟수
		    uint sum; // 거래 금액
		    uint statusIndex;  // 등급 인덱스
		  }
		  ```
	- 상태 변수 & 매핑 & 제한자
		- ```solidity
		  address public hlToken; // 토큰 CA 주소
		  GradeStatus[] public status; // 등급 리스트
		  mapping(address => MemberHistory) public tradingHistory; // 회원별 거래 이력
		  modifier onlyToken() {
		    require(msg.sender == hlToken);
		    _;
		  }
		  ```
	- 토큰 주소 설정
		- ```solidity
		  function setToken(address addr) external onlyOwner {
		    hlToken = addr;
		  }
		  ```
	- 새로운 등급 추가
		- ```solidity
		  function pushStatus(string calldata _grade, uint times, uint _sum, uint _rate) external onlyOwner {
		    status.push(GradeStatus({
		      grade: _grade,
		      times: _times,
		      sum: _sum,
		      rate: _rate
		    }));
		  }
		  ```
