
## Solidity 실습
### 자료 타입 - 참조 타입
- #### 배열
	- 컴파일 시점에 고정된 크기, 동적 크기 가질 수 있음
	- 고정된 크기는 T\[k], 동적 크기는 T\[]와 같이 선언
	- `uint[][3]` : 동적 배열로 구성된 크기가 3인 uint 타입 배열
	- `boold[2][]` : 크기가 2인 배열로 구성된 bool 타입 동적 배열
- #### 문자열과 바이트 배열
	- bytes 동적 배열은 참조 타입으로 동작
		- 동적 배열은 push() 함수를 이용하여 마지막 요소를 추가 가능
	- string은 bytes와 유사하지만 index 접근 안됨
		- EVM에서는 두 타입 모두 바이트 배열로 구현
	- ```solidity
	  contract BytesAndString {
	      string internal constant TITLE = "HELLO";
	      bytes internal bytesTitle = bytes(TITLE);
	      
	      function getTitleString() public pure returns (string memory) {
	          return TITLE;
	      }
	      
	      function getTitleBytes() public view returns (bytes memory, uint) {
	          return (bytesTitle, bytesTitle.length);
	      }
	      
	      function appendTitle() public {
	          for(uint i = 0; i < bytesTitle.length; i++) {
	              bytesTitle[i] = 'a';
	          }
	          bytesTitle.push('!');
	          bytesTitle = bytes.concat(bytesTitle, bytes("@@"));
	      }
	  }
	  ```
		- **pure** : constant 값을 pure로 읽기 가능
- #### 구조체
	- struct 키워드로 문자열, 정수 등의 변수를 그룹화 할 수 있는 사용자 정의 유형
		- ```solidity
		  contract Structs {
		      struct Voter {
		          uint weight;
		          bool voted;
		          adress delegate;
		          uint vote;
		      }
		      
		      User[] public users;
		      
		      function addUser(string calldata _name, string calldata _email) public {
		      users.push(User(_name, _email));
		      }
		  }
		  
		  ```
### 매핑 타입과 타입 캐스팅
- #### 매핑 (Mapping)
	- mapping(keytype => valuetype) 으로 정의하며 크기 제한이 없음
		- keytype : 모든 기본값 가능 but 다른 매핑, 구조체, 동적 배열 불가
		- valuetype : 어떤 타입이든 가능
	- 스토리이제만 선언 가능
	- 지역 변수 사용 시 참조 형식으로만 가능
		- 매핑 전체는 삭제 불가능
		- 키 단위로는 삭제 가능
		- `mapping(address => User) internal users;`
- #### 타입 캐스팅
	- 크기가 작은 타입을 큰 타입으로 변경하는 의미
		- 반대로 캐스팅 할 시 자료 손실 발생 가능
		- 일반적으로 컴파일러가 자동으로 캐스팅하지만 개발자가 직접 명시 가능
		- `int8 y = -3;`
		- `uint8 x = uint8(y);`

### 함수와 제어 구조
- #### 가시성
	- Public : 모든 컨트랙트 및 계정에서 호출 가능
	- Private : 컨트랙트 안에서만 사용 가능
	- Internal : 컨트랙트 안 또는 상속받은 파생 컨트랙트에서만 호출 가능
	- External : 다른 외부 컨트랙트, 계정에서 호출 가능 (내부 사용 불가능)
- #### 속성
	- view : 블록체인의 상태변수가 변경되지 않음
	- pure : 블록체인의 상태변수가 변경되지 않고, 읽지도 않음
- #### 제어 구조
	- if, else, while, do, for, break, continue, return 사용 가능
	- switch, goto 는 없음
- #### 내부, 외부 함수 호출
	- 내부 재귀 함수는 문법적으로 호출 가능하나 가스 한도 내에서 실행
	- (외부) 컨트랙트 / 인터페이스 타입으로 인자 받아 실행
- #### 에러 처리
	- require(bool) : 조건 안 맞을 시 되돌려짐, 입력, 외부구성요소의 오류에 사용
	- require(bool, string) : 위와 동일, 오류메시지 제공
	- revert() : 실행 중단하고 상태 변경사항을 되돌림
	- revert(string) : 위와 동일, 오류 메시지 제공
	- assert(bool) : 내부 상태 에러가 없는지 확인, 에러 발생 시 모든 가스 소비
- #### 제한자 (Modifier)
	- 함수 실행 전후에 동작을 자동으로 추가
		- 코드 중복을 줄이고 유지 보수성을 높임
	- 주로 접근제어, 사전 조건 검사, 재진입 방지 등에 사용
	- ```solidity
	  contract Modifier {
	    address public owner;
	    
	    constructor() {
	      owner = msg.sender;
	    }
	    
	    modifier onlyOwner {
	      // 함수 실행 전 조건
	      if(msg.sender != owner) revert(unicode"컨트랙트 소유자만 호출 가능");
	      
	      // 함수 실행 위치
	      _;
	      
	      // 함수 실행 후 조건
	      assert(owner != address(0));
	    }
	    
	    function changeOwner(address _owner) public onlyOwner {
	      owner = _owner;
	    }
	  }
	  ```
### 이벤트
- #### 이벤트
	- 트랜잭션 로그 영수증에 저장하고 출력
	- 블록체인에 데이터를 가장 저렴하게 기록 가능
		- 주로 로그를 남기기 위해 사용
		- ```solidity
		  contract Events {
		    event Log(address sender, string message);
		    event AnotherLog();
		    
		    function test(string memory msg1, string memory msg2) public {
		      emit Log(msg.sender, msg1);
		      emit Log(msg.sender, msg2);
		      emit AnotherLog();
		    }
		  }
		  ```
### 상속
- #### 상속
	- is 키워드를 이용하여 상속 가능, 여러 부모를 다중 상속도 가능
	- 오버라이딩 허용
		- 부모 컨트랙트에서 virtual 키워드 이용
		- 제한을 강화하는 방향으로 변경 가능
			- ex) (부모) view -> (자식) pure
